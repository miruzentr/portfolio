# 🎨 Portfolio — Miruzen

Personal portfolio — dark neon, neon-green, snake-coded 🐍

**Live:** https://miruzentr.github.io/portfolio/

## ✨ Features

- 🌐 **Interactive particle network** — canvas yang nyambung ke cursor
- 🌌 **Aurora glow background** animasi
- ⌨️ **Typing animation** multi-kata di hero
- 🃏 **3D tilt cards** + cursor-follow glow
- 📊 **Animated stat counters**
- 🕓 **Journey timeline**
- 📈 **Scroll progress bar** + back-to-top
- 🎬 Scroll-reveal (IntersectionObserver)
- 📱 Fully responsive + `prefers-reduced-motion` support

## 🚀 Run locally

```bash
python3 -m http.server 8080
# buka http://localhost:8080
```

## 🌐 Deploy

Auto-deploy lewat GitHub Actions → GitHub Pages (`.github/workflows/deploy.yml`).

# 🎨 Portfolio — Miruzen

Personal portfolio website — dark, neon, snake-coded. 🐍

**Stack:** HTML + CSS + vanilla JS. No frameworks, no build step, no dependencies.

## ✨ Features

- ⌨️ Typing animation di hero
- 🌌 CSS-only starfield background
- 💻 Fake terminal "whoami" card
- 🎬 Scroll-reveal animations (IntersectionObserver)
- 📱 Fully responsive

## 🚀 Run locally

```bash
# buka langsung
open index.html

# atau pakai server
python3 -m http.server 8080
```

## 🌐 Deploy

Aktifkan GitHub Pages: **Settings → Pages → Deploy from branch → main → / (root)**
